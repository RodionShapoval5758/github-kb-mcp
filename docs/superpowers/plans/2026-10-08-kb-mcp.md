# KB MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only remote MCP server on Render that lets Claude (web, mobile, voice) navigate, read and search one GitHub-hosted project knowledge base live.

**Architecture:** One Python ASGI app: a bearer-token ASGI middleware in front of the MCP SDK's stateless streamable-HTTP app. Four thin tools (`get_context`, `list_dir`, `read_file`, `search`) format text for voice; a single `GitHubReader` class is the only code that talks to GitHub (REST API, read-only PAT). Nothing is cached or stored.

**Tech Stack:** Python ≥ 3.12, `mcp` 2.x (`MCPServer`), `httpx`, `uvicorn`, `starlette` (via `mcp`), `uv` for local dev, Render free web service (native Python runtime, `render.yaml`).

**Spec:** `docs/superpowers/specs/2026-10-08-kb-mcp-design.md`

## Post-review changes (applied after implementation)

The code in `src/` is authoritative where it differs from the snippets below:
- `normalize_path` resolves `..` inside the KB and rejects only paths that climb above the root.
- `GitHubReader._get(what=None)`: a 404 on the git tree or tarball raises `KBUnavailableError` ("repository or branch is not reachable…"), and every 404 is logged.
- `app.py` sets the `httpx` logger to WARNING, so the tarball redirect's temporary token isn't logged.

## Global Constraints

- `mcp>=2.3,<3`. Import `from mcp.server.mcpserver import MCPServer`. `mcp.server.fastmcp` does not exist in 2.x (it raises `ModuleNotFoundError`).
- Build the app with `server.streamable_http_app(stateless_http=True, json_response=True, host="0.0.0.0")`. With the default `host="127.0.0.1"` the SDK enables DNS-rebinding protection that rejects the Render `Host` header.
- Register every `@server.custom_route` **before** calling `streamable_http_app()`.
- Read-only: only HTTP GET to GitHub. No write tools.
- Every tool: `@server.tool(annotations=READ_ONLY, structured_output=False)`, returns `str`.
- Anticipated failures raise a subclass of `KBError` (which subclasses the SDK's `ToolError`), so the message reaches Claude.
- Never log bearer tokens, the GitHub token, or file contents.
- **No automated tests** (user's global rule: never write tests unless explicitly asked). Each task ends with a manual verification step with commands and expected output.
- No code comments unless the WHY is non-obvious.
- Commit messages: single line, `type: message` or `type(scope): message`, no body, no `Co-Authored-By`. **Commit only when the user explicitly asks.** Each task lists a suggested message.
- Local run command (used throughout): `uv run --env-file .env uvicorn kb_mcp.app:app --port 8000`

## Review Focus

1. Connector header typed **without** the `Bearer ` prefix (Claude sends header values exactly as typed). It must still authenticate. Covered in Task 2, Step 3.
2. Paths like `../other`, `/INDEX.md`, `./a//b.md`, `a\b.md`. They must be normalized or rejected, and must never reach another repo or API endpoint. Covered in Task 3, Step 3.
3. Binary files (images, PDFs) and files over 1 MB (long transcripts). Binary files are refused with a clear message, and large text is fetched raw and paginated. Covered in Task 4, Step 3 and Task 7, Step 3.
4. Expired or revoked GitHub token, or a rate limit. Claude gets a "temporarily unavailable" sentence, the server log shows the GitHub status, and no traceback reaches the client. Covered in Task 4, Step 3.
5. Root index missing or `KB_ROOT_INDEX` wrong. `get_context` returns an error telling Claude to use `list_dir`/`search`, not a crash. Covered in Task 5, Step 5.

```python
import os
from dataclasses import dataclass

MIN_TOKEN_LENGTH = 32


class ConfigError(Exception):
    pass


@dataclass(frozen=True)
class Settings:
    github_token: str
    kb_repo: str
    kb_branch: str
    kb_root_index: str
    bearer_tokens: tuple[str, ...]


def _require(name: str) -> str:
    value = os.environ.get(name, "").strip()
    if not value:
        raise ConfigError(f"Missing required environment variable {name}")
    return value


def _optional(name: str, default: str) -> str:
    return os.environ.get(name, "").strip() or default


def load_settings() -> Settings:
    github_token = _require("GITHUB_TOKEN")

    kb_repo = _require("KB_REPO")
    owner, _, name = kb_repo.partition("/")
    if not owner or not name or "/" in name:
        raise ConfigError("KB_REPO must look like 'owner/name'")

    tokens = tuple(t.strip() for t in _require("MCP_BEARER_TOKENS").split(",") if t.strip())
    if not tokens or any(len(t) < MIN_TOKEN_LENGTH for t in tokens):
        raise ConfigError(f"Every MCP_BEARER_TOKENS entry must be at least {MIN_TOKEN_LENGTH} characters")

    return Settings(
        github_token=github_token,
        kb_repo=kb_repo,
        kb_branch=_optional("KB_BRANCH", "main"),
        kb_root_index=_optional("KB_ROOT_INDEX", "INDEX.md"),
        bearer_tokens=tokens,
    )
```

````markdown
## Invariants and gotchas

- **Read-only.** Only GET requests to GitHub, and no write tools. Writes would need their own design.
- **MCP SDK 2.x:** use `from mcp.server.mcpserver import MCPServer`. `mcp.server.fastmcp` no longer exists.
- `streamable_http_app(..., host="0.0.0.0")` is required. The default localhost host enables a Host-header check that rejects the Render hostname.
- Register `custom_route`s before calling `streamable_http_app()`.
- Anticipated failures raise a `KBError` subclass, and its message is shown to Claude. Any other exception reaches Claude only as "Error executing tool".
- The 401 response deliberately has no `WWW-Authenticate` OAuth metadata, so Claude's connector dialog doesn't try OAuth. Bare tokens (no `Bearer ` prefix) are accepted because the connector sends the header value exactly as typed.
- Tool output is short plain text (`structured_output=False`), because conversations are often spoken. Keep the tool count small and the descriptions explicit.
- Never log tokens or file contents.
- Don't use GitHub's code-search API for `search`. Its index lags behind pushes.
- The Render free tier sleeps after ~15 min idle. Open `/health` before a voice session.
````

- [ ] **Step 1: Write `src/kb_mcp/auth.py`**

```python
import hmac
from collections.abc import Sequence

from starlette.responses import JSONResponse
from starlette.types import ASGIApp, Receive, Scope, Send


class BearerAuth:
    def __init__(self, app: ASGIApp, tokens: Sequence[str], protected_prefix: str = "/mcp"):
        self._app = app
        self._tokens = [t.encode() for t in tokens]
        self._prefix = protected_prefix

    async def __call__(self, scope: Scope, receive: Receive, send: Send) -> None:
        if scope["type"] == "http" and scope["path"].startswith(self._prefix) and not self._authorized(scope):
            # No WWW-Authenticate OAuth metadata: Claude's connector dialog would otherwise try an OAuth flow.
            await JSONResponse({"error": "unauthorized"}, status_code=401)(scope, receive, send)
            return
        await self._app(scope, receive, send)

    def _authorized(self, scope: Scope) -> bool:
        header = dict(scope["headers"]).get(b"authorization", b"").strip()
        scheme, _, rest = header.partition(b" ")
        # Claude sends the header value exactly as typed, so accept a bare token as well as "Bearer <token>".
        token = rest.strip() if scheme.lower() == b"bearer" else header
        return bool(token) and any(hmac.compare_digest(token, t) for t in self._tokens)
```

- [ ] **Step 1: Write `src/kb_mcp/github_reader.py`**

```python
import base64
import logging
from urllib.parse import quote

import httpx

from .errors import InvalidPathError, KBNotFoundError, KBUnavailableError
from .paths import normalize_path

GITHUB_API = "https://api.github.com"

log = logging.getLogger(__name__)


def is_binary(raw: bytes) -> bool:
    return b"\x00" in raw[:8192]


class GitHubReader:
    def __init__(self, repo: str, branch: str, token: str, client: httpx.AsyncClient | None = None):
        self._repo = repo
        self._branch = branch
        self._client = client or httpx.AsyncClient(
            base_url=GITHUB_API,
            headers={
                "Authorization": f"Bearer {token}",
                "Accept": "application/vnd.github+json",
                "X-GitHub-Api-Version": "2022-11-28",
            },
            timeout=15.0,
            follow_redirects=True,
        )

    async def _get(self, url: str, *, what: str, **kwargs) -> httpx.Response:
        try:
            response = await self._client.get(url, **kwargs)
        except httpx.HTTPError as exc:
            log.warning("GitHub request %s failed: %r", url, exc)
            raise KBUnavailableError("Could not reach GitHub. Try again in a moment.") from exc
        if response.status_code == 404:
            raise KBNotFoundError(f"Not found in the knowledge base: {what}. Use list_dir or search to find the right path.")
        if response.is_error:
            log.error("GitHub request %s returned %s: %s", url, response.status_code, response.text[:300])
            raise KBUnavailableError(
                "The knowledge base is temporarily unavailable (GitHub refused or rate-limited the request)."
            )
        return response

    async def read_text(self, path: str) -> str:
        clean = normalize_path(path)
        if not clean:
            raise InvalidPathError("Give a file path, not the repository root. Use list_dir to see the top level.")
        url = f"/repos/{self._repo}/contents/{quote(clean)}"
        data = (await self._get(url, what=clean, params={"ref": self._branch})).json()
        if isinstance(data, list):
            raise InvalidPathError(f"{clean} is a folder. Use list_dir to see what it contains.")
        if data.get("type") != "file":
            raise InvalidPathError(f"{clean} is not a regular file.")
        if data.get("encoding") == "base64":
            raw = base64.b64decode(data["content"])
        else:
            # Files over 1 MB come back without inline content; fetch them raw.
            raw_response = await self._get(
                url, what=clean, params={"ref": self._branch}, headers={"Accept": "application/vnd.github.raw+json"}
            )
            raw = raw_response.content
        if is_binary(raw):
            raise InvalidPathError(f"{clean} is a binary file; only text files can be read.")
        return raw.decode("utf-8", errors="replace")
```

```python
DEFAULT_READ_CHARS = 15_000
MAX_READ_CHARS = 50_000


def paginate(path: str, text: str, offset: int, max_chars: int) -> str:
    size = min(max(max_chars, 1), MAX_READ_CHARS)
    start = min(max(offset, 0), len(text))
    end = min(start + size, len(text))
    if start == 0 and end == len(text):
        return f"# {path}\n\n{text}"
    header = f"# {path} (characters {start}–{end} of {len(text)})\n\n"
    if end < len(text):
        footer = f"\n\n[continues — call read_file with path={path!r} and offset={end}]"
    else:
        footer = "\n\n[end of file]"
    return header + text[start:end] + footer
```

```python
        response = await self._get(
            f"/repos/{self._repo}/git/trees/{quote(self._branch)}",
```

```python
def _extract_text_files(archive_bytes: bytes) -> list[tuple[str, str]]:
    files = []
    with tarfile.open(fileobj=io.BytesIO(archive_bytes), mode="r:gz") as archive:
        for member in archive:
```

### Task 11: Search ranking (`search.py`)

**Files:**
- Create: `src/kb_mcp/search.py`

**Interfaces:**
- Consumes: nothing (pure)
- Produces:
  - `kb_mcp.search.Hit` (frozen dataclass): `path: str`, `score: int`, `snippets: tuple[tuple[int, str], ...]`, where each snippet is (1-based line number, line text up to 200 chars)
  - `kb_mcp.search.search_files(files: Iterable[tuple[str, str]], query: str, scope: str = "", limit: int = 10) -> list[Hit]`

- [ ] **Step 1: Write `src/kb_mcp/search.py`**

```python
from collections.abc import Iterable
from dataclasses import dataclass

MAX_SNIPPETS_PER_FILE = 3
SNIPPET_CHARS = 200
PATH_HIT_WEIGHT = 10


@dataclass(frozen=True)
class Hit:
    path: str
    score: int
    snippets: tuple[tuple[int, str], ...]


def _snippets(text: str, terms: list[str]) -> tuple[tuple[int, str], ...]:
    found = []
    for number, line in enumerate(text.splitlines(), start=1):
        lower_line = line.lower()
        if any(term in lower_line for term in terms):
            found.append((number, line.strip()[:SNIPPET_CHARS]))
            if len(found) == MAX_SNIPPETS_PER_FILE:
                break
    return tuple(found)


def search_files(files: Iterable[tuple[str, str]], query: str, scope: str = "", limit: int = 10) -> list[Hit]:
    terms = query.lower().split()
    if not terms:
        return []
    prefix = f"{scope}/" if scope else ""
    hits = []
    for path, text in files:
        if not path.startswith(prefix):
            continue
        lower_path, lower_text = path.lower(), text.lower()
        if not all(term in lower_text or term in lower_path for term in terms):
            continue
        score = sum(lower_text.count(term) for term in terms)
        score += PATH_HIT_WEIGHT * sum(term in lower_path for term in terms)
        hits.append(Hit(path, score, _snippets(text, terms)))
    hits.sort(key=lambda h: (-h.score, h.path))
    return hits[:limit]
```

- [ ] **Step 2: Add the tool inside `register_tools`, after `list_dir`**

```python
    @server.tool(annotations=READ_ONLY, structured_output=False)
    async def search(query: str, path: str = "", limit: int = 10) -> str:
        """Find documents whose name or text contains ALL the given words (case-insensitive), across the whole knowledge base or under one folder (path). Use it when the indexes don't point to what you need. Returns ranked paths with matching lines; open them with read_file."""
        if not query.split():
            raise KBError("search needs at least one word.")
        scope = normalize_path(path)
        files = await reader.snapshot_text_files()
        hits = search_files(files, query, scope=scope, limit=max(1, min(limit, MAX_SEARCH_RESULTS)))
        where = f" under {scope}" if scope else ""
        if not hits:
            return f"No documents match {query!r}{where}. Try fewer or different words."
        lines = [f"{len(hits)} documents match {query!r}{where}:"]
        for hit in hits:
            lines.append(f"\n{hit.path}")
            lines.extend(f"  line {number}: {snippet}" for number, snippet in hit.snippets)
        return "\n".join(lines)
```
